## 📌 Convenciones Iniciales de Fase I

Durante la Fase I, el desarrollo del frontend se regía por las siguientes convenciones iniciales:

- **Framework**: React 18 con TypeScript en modo estricto.
- **Herramienta de Build**: Vite.
- **Estructura de Directorios**: Estructura basada en `src/components`, `src/pages`, `src/services` e `src/hooks`.
- **Estilos**: CSS Modules y utilidades CSS básicas.
- **Manejo de Estado**: React Context API para estado global de autenticación y estado local de componentes.
