# 📜 Fase I — Documentación Histórica (Release v1)

Este directorio contiene la documentación técnica congelada al término de la **Fase I (MVP histórico)** del repositorio `tartis-recon-ai-parking-frontend`.

---

## 📌 Resumen Ejecutivo de la Fase I

En la Fase I se entregó la primera versión funcional de la plataforma TARTIS Recon-AI Parking en formato de **aplicación web monolítica**. Esta versión sentó las bases de la interfaz de usuario para el monitoreo de accesos, gestión de plazas y autenticación con Keycloak.

### Características de la Fase I:
- Estructura monolítica en React + Vite.
- Integración directa con los microservicios backend de control de accesos e incidencias.
- Despliegue en contenedor Docker único tras servidor Nginx.
